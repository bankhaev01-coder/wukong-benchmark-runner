# Wukong Benchmark Runner

Тестовое решение для автоматизации локального запуска **Black Myth: Wukong Benchmark Tool** из Steam.

## Запуск

```powershell
dotnet run --project .\WukongBenchmarkRunner -- detect
dotnet run --project .\WukongBenchmarkRunner -- dry-run
dotnet run --project .\WukongBenchmarkRunner -- run --timeout-minutes 30 --output C:\Temp\wukong-report.json
dotnet run --project .\WukongBenchmarkRunner -- parse --results-path C:\Temp\results
```

Если Steam или конфигурация не находятся автоматически, используйте `--steam-path` и `--config`.

## Архитектура и адаптация

Оркестратор не зависит от деталей Steam и формата файлов: поиск установки, Unreal INI, запуск процесса, сбор сведений о ПК и парсинг результатов выделены в отдельные адаптеры. Это позволяет адаптировать решение под другой benchmark без изменения последовательности сценария.

`GameUserSettings.ini` резервируется перед началом и восстанавливается в `finally`, включая сценарий ошибки. Профили фиксируют назначение и все применяемые параметры в JSON-отчёте.

CPU-профиль уменьшает разрешение и отключает дорогие GPU-функции, оставляя повышенную дальность видимости. GPU-профиль использует максимальные значения качества, масштаб 100% и Ray Tracing. Это практические CPU/GPU-oriented прогоны, а не абсолютно чистые лабораторные измерения: игровой benchmark всегда содержит смешанную нагрузку.

Результаты ищутся среди свежих `.json`, `.csv`, `.txt` и `.log` в `Saved` и каталоге конфигурации. Распознаются average/avg, minimum/min, maximum/max FPS и score. Если конкретная версия приложения использует другой формат, отчёт содержит предупреждение вместо выдуманных данных.

## Ограничения

- Реальный запуск требует установленного Benchmark Tool, авторизованного Steam и Windows.
- Названия Unreal-параметров могут различаться между версиями игры; перед сдачей задания нужно проверить их на целевой установке.
- Включение Ray Tracing не гарантирует его применение драйвером или конкретной видеокартой.
