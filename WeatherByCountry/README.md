# Погода по городам и странам

Консольное приложение на C# читает города из `Cities.txt`, запрашивает текущую погоду из [wttr.in](https://wttr.in/) и выводит температуру в градусах Цельсия. Затем приложение группирует успешные результаты по странам и вычисляет количество городов, среднюю, минимальную и максимальную температуру.

## Требования

- .NET SDK 10.
- Доступ к интернету и API `https://wttr.in/{City}?format=j1`.
- Внешние NuGet-пакеты не используются: HTTP-клиент и `System.Text.Json` входят в .NET.

## Запуск

Из корня репозитория:

```powershell
dotnet run --project .\WeatherByCountry
```

По умолчанию читается `Cities.txt`, включённый в приложение. Чтобы прочитать собственный файл, передайте путь первым аргументом:

```powershell
dotnet run --project .\WeatherByCountry -- "C:\путь\к\Cities.txt"
```

Файл должен содержать по одному названию города на строку. Пустые строки пропускаются, дубликаты удаляются без учёта регистра.

## Пример вывода

```text
Tokyo, Japan +18 °C

Сводка по странам:
Japan — городов: 3, средняя: +19 °C, минимум: +16 °C, максимум: +22 °C
```

Температура и сводка вычисляются из фактического ответа API при каждом запуске; пример приведён только для иллюстрации формата. Если запрос или разбор ответа для конкретного города не удался, приложение сообщает об ошибке и продолжает обработку остальных городов. Сводка включает только успешно полученные данные.
